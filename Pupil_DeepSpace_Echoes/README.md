# 瞳 · Pupil — 深空回响

离线可玩的非对称追逐游戏。靠近蜗灵建立联结，用尾流加速自己、拖慢追猎者；完整连接三只未被催眠的蜗灵即可获胜。

## 开始游玩

解压整个文件夹，双击 `pupil.html`。作弊器入口是 `cheat.html`，游戏设置中也有入口。保留 `css`、`js` 和 `assets` 文件夹的位置。

所有美术由 Canvas 程序绘制，中文字库随工程附带，无需联网下载图片、字体或依赖。`standalone` 中另有自包含的游戏和作弊器，可分别双击打开。

- 单人：控制行者，追猎者自动追击并使用主技能。
- 本地双人：方向键控制行者，WASD 控制追猎者。
- 练习追猎：你控制追猎者，行者自动行动。
- 主界面可独立选择行者 AI 与追猎者 AI 的五档操练难度，并调整数值偏差、触屏按键和环境音。环境音默认关闭。
- 双 AI 观战：双方自动操练，可比较不同组合与难度。

## 这一版：流动与回响

### 原版碰撞与果冻形变

`js/physics.js` 与最初上传的游戏中软体物理段逐字一致。角色半径 24 / 核心碰撞半径 7，追猎者半径 42 / 核心碰撞半径 14；32 顶点、弹簧、阻尼、挤压、贴边、薄膜穿行和蜗灵碰撞规则均保留。实体更新中的约束中心、软体更新、形变阻力与挤压后回弹仍使用原版逻辑。

外观直接使用这 32 个软体顶点作为身体轮廓，内部流光、粒子、虹膜和光斑裁剪在轮廓内。恢复原版贴边凹陷与脱离回弹；增加水中漂游的视觉尾鳍、流动光脉和弹性膜面。装饰尾鳍没有碰撞体。角色、追猎者、选择界面、结算与作弊器共用流体材质。

蜗灵恢复原版主体绘制，去掉后来加上的螺旋壳与触角。岩石增加孔洞、矿脉、裂缝、层理和朝向光源的边缘高光，纹理缓存复用。

运行 `python tools/verify_core.py` 可核对原版物理文件指纹和全部碰撞 / 弹性常量。

行者在安全时优先完成部分联结，追逐中选择绕圈拉点和逃生路线，提前使用 P 喷尾建立尾流；不同专属技能有独立判断。追猎者根据最近观测到的位置和速度预判拦截，通过网格寻路与局部转向绕障，烬烟会按难度预判烟弹交会点；高档会避开浓尾流、使用漂移、强化或召唤配合。暗夜和迷障限制其观察距离，失去目标后只短暂记忆最后位置，然后巡游。

### 夜景与结算

夜晚使用每盏光源独立的遮挡层，岩石形成遮光区与渐软的阴影边缘，薄膜透光。玩家、追猎者、蜗灵、神坛、灵光与光锚有距离衰减和弱色彩投射；多盏光能填充彼此阴影。

行者胜利使用“三灵共鸣”，追猎者胜利使用“追猎完成”。两种全屏结算包含动态获胜者插画、实际旅程时长、联结或生命数据，以及操练难度。手机布局将插画与内容上下排列。单人 / 练习模式跟随当前操纵的生物；本地双人自动让双方进入画面。按住 Tab 查看追逐全景。

## 平衡与修正

- 追猎者基础速度上限从 640 调至 580，基础接触伤害从 55 调至 44。各追猎者的独立移速百分比现在实际参与计算。
- 绯渊攻击范围 205、伤害倍率 1.02、冷却 5 秒；苍噬冷却 7 秒，蚀影冷却 6 秒。
- 镜的反击眩晕统一为 2.2 秒，移除原来的 3–8 秒随机长控制。
- 幼蛛命中伤害 18，遵循全局伤害倍率和护盾减伤。普通烟弹爆炸按距离衰减，最高 24 伤害，避免近距离随机秒杀。
- 烟层增伤作用于追猎者对行者的攻击；停止受到烟弹影响后，每 4 秒自然减少一层。烬烟在自动模式下会使用烟弹。
- 全局伤害倍率同时作用于持续攻击、燃烧、幼蛛、普通烟弹爆炸和新增技能。
- 修复作弊器全局倍率在变量初始化前读取失败、烟弹充能设置未生效、零伤害倍率被默认值覆盖、雾的迷障无法再次按键取消，以及失败状态被胜利覆盖等问题。

## 作弊器与配置

所有修改自动保存，支持角色 / 追猎者 / 全局分别重置、全局标准 / 舒缓 / 高压预设、JSON 复制、下载、粘贴导入和文件导入。导入会检查数值类型和范围，并补齐新增角色与追猎者的缺省项。

若两个页面通过同一站点地址打开，修改后游戏会自动重新载入。浏览器可能隔离本地文件的存储：此时在作弊器下载或复制 JSON，再在游戏的“设置 → 导入配置”中应用。

需要共享实时修改时，可在此文件夹运行 `python -m http.server 8000`，随后打开 `http://localhost:8000/pupil.html` 和 `http://localhost:8000/cheat.html`。

## 工程结构

- `js/config.js`：常量、八位角色、七位追猎者、地图与共享默认数值。
- `js/art.js` / `fluid-art.js`：缓存虹膜、流体膜面、粒子和共用生物美术。
- `js/state.js`：状态与偏好、作弊器覆盖读取。
- `js/physics.js` / `input.js` / `world.js`：软体物理、输入、地图生成。
- `js/skills.js` / `entities.js` / `combat.js`：原有技能、实体更新、战斗。
- `js/expansion.js`：新增技能、边界检查、预警与有上限的控制。
- `js/camera.js` / `textures.js` / `render.js`：基础视角、纹理、地图与特效。
- `js/ecology.js`：两张新地图、四种外来生物与植被渲染。
- `js/ai.js`：五档独立 AI、预判、寻路、拉点与技能决策。
- `js/visuals.js` / `lighting.js`：原版顶点外观、岩石材质、局部光影、视角与小地图。
- `js/results.js`：两种全屏动态结算界面。
- `js/interface.js` / `controls.js`：响应式界面、对局信息和触屏按钮。
- `js/laboratory.js`：作弊器逻辑与配置检查。
- `css`：游戏、触屏控制和作弊器样式。
- `assets/fonts`：裁剪后的 Noto 中文字体和 SIL Open Font License。
- `tools/build_standalone.py`：从多文件工程重新生成单文件版。
- `tools/verify_core.py`：校验保留的碰撞与软体物理。

采用按顺序加载的普通脚本，便于直接双击离线运行。修改共享数据或美术后，游戏和作弊器自动使用同一来源；无需分别维护两套角色名单。
